The backbone drill, working.

This is Degree ID — the drill everything else is built on. Not "name that interval" in a vacuum: a cadence puts you in a key, then one note sounds, and you say what it is in that key. That's the skill that actually transfers to real music.

  • 1A cadence establishes G major. Voicing and instrument randomize, so you key off the tonality — not a memorized sound.
  • 2One note sounds. Tap the scale degree you heard. Keyboard 1–7 works too.
  • 3Feedback is musical. Right: the note resolves to tonic. Wrong: you hear your answer, then the real one, back to back.
  • 4The combo rises in pitch. Three in a row and the confirmation climbs the scale — a hot streak literally sounds like an arpeggio.

Prototype audio is a simple synth. The real app uses sampled piano with a synth fallback, so it always makes sound — even offline before samples cache.

What I'd like decided before we build.

Everything above is documented in /docs, broken into work packages that can run as parallel sessions. These five are the calls that change what gets built.

01

Is the drill loop fun?

Play the Degree ID drill above a dozen times. If the 2-second micro loop isn't satisfying on its own, no amount of map and streaks will save it — and that's the thing to fix first.

02

Brass on near-black, or something else?

The accent is instrument-lacquer gold with a teal for anything live. Hit the theme button to see "Paper", the light theme — some readers strongly prefer black notation on white.

03

Numbers or solfège by default?

Degrees can read 1–7 or Do Re Mi. Both ship as a setting — the question is which one a new user meets first, and whether minor is la-based or do-based.

04

Anonymous forever, or accounts?

Local-first means no signup and instant start, but clearing browser data loses progress. JSON export covers it — is that enough, or do we want sync sooner than Phase 5?

05

First milestone scope.

My proposal: an installable, offline functional ear trainer with spaced repetition — Degree ID only — before touching the other three pillars. It validates the loop cheaply and is already better than most of the market.
